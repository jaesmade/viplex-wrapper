# Repository instructions

## Milestone commits

Use this workflow when a feature, fix, or release checkpoint is ready to commit.

1. Run the [project checks](MASTER.md#verification) relevant to the changes and record any checks that remain pending.
2. Add a dated entry to [MILESTONES.md](MILESTONES.md) with what changed and the verification results.
3. Review and stage the milestone's files and `MILESTONES.md`, then make a local Git commit using `feat: <changes>`. Replace `<changes>` with a short description. Keep unrelated work out of the commit.
